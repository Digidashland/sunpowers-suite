LOGIN KAISE HOGA (sabke liye)
  • Pehli baar: email par OTP (6 ank) → apna PIN banayein → 2 security sawal
      Admin = 6 ank ka PIN, baaki sab (team, dealer, customer) = 4 ank ka PIN

  • Naya phone/computer: phir email OTP → PIN
  • PIN bhool gaye: security sawal ke jawab → naya PIN
      5 baar galat jawab → email par reset link (15 minute chalega, ek hi baar)
  • Admin Panel: har baar PIN maangta hai (tab band = logout). Naye computer par pehle OTP
  • Admin OTP SIRF helpsunpowers@gmail.com par jayega.
    surajanandpbh@gmail.com = backup — sirf "Backup email par bhejein" dabane par
  • Emergency (email nahi khul raha): Admin login me "Master password" → purana Store Admin
    password + 6 ank ka PIN

SAB EK DOOSRE SE JUDE HAIN (ek hi database)
  • Website ka form   → Admin "पूछताछ" + CRM "Store Orders → Enquiry"
  • Main App ka order → Admin "ऑर्डर" + CRM "Store Orders" (ghanti bajegi)

  • CRM ka product → "Store ko bhejein" → Admin jaanch kar Publish → Main App par live
