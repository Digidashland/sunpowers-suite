LOGIN KAISE HOGA (sabke liye)
  * Pehli baar: email par OTP (6 ank) -> apna PIN banayein -> 2 security sawal
      Admin = 6 ank ka PIN, baaki sab (team, dealer, customer) = 4 ank ka PIN
  * Phir usi phone/computer par: sirf PIN. Login tab tak bana rahega jab tak khud Logout na karein
  * Naya phone/computer: phir email OTP -> PIN
  * PIN bhool gaye: security sawal ke jawab -> naya PIN. 5 baar galat -> email par reset link (15 minute, ek baar)
  * Admin Panel: har baar PIN maangta hai (tab band = logout). Naye computer par pehle OTP
  * Admin OTP SIRF helpsunpowers@gmail.com par jayega. surajanandpbh@gmail.com = backup — sirf "Backup email par bhejein" dabane par
  * Emergency (email nahi khul raha): login me "Master password" -> purana Store Admin password + PIN
  * Team: CRM -> Team -> har user ka EMAIL zaroor bharein (OTP usi par jata hai). PIN atak jaye: user kholein -> "Login reset"
  * Profile -> Suraksha: PIN/sawal badlein, apne phone/computer dekhein, sab se logout

CRM SHURU KAREIN (Admin)
  1. Settings -> Company: legal naam, GSTIN, pata, logo, sign
  2. Settings -> Bill / Quotation: bank, UPI, terms, number series
  3. Settings -> Accountant: CA ka naam + WhatsApp + email
  4. Team -> Naya user (email zaroori): Manager / Staff / Dealer / Influencer (commission, discount limit, target)
  5. Products & Projects -> items jodein (ya Excel se)
  Dealer / Influencer khud bhi "ID banayein" kar sakte hain -> Team -> Verify baaki -> Chalu karein
  * Har user ko sirf apna data — Admin ko sab. Permission: Team -> Role permission, ya user kholein -> "alag permission"
  * Ek mobile = ek customer. Customer kaise banta hai: Leads (har jagah se, path ke saath) -> Customers -> "Add New Customer" (pehle path, phir poori jaankari)
  * Quotation -> "Bill banayein" -> Payment jodein -> Rasid WhatsApp. Stock apne aap ghatta/badhta hai
  * Product seedha store par live NAHI hota: CRM "Store ko bhejein" -> Store Admin "CRM se aaye product" -> Google/Meta jaanch -> Publish (ya "Lautayein")

SAB EK DOOSRE SE JUDE HAIN
  * Website ka form    -> Admin "poochtaachh" + CRM Leads (path = Website / ad channel)
  * Online Store order -> Admin "orders" + CRM Store Orders (ghanti bajegi) + CRM Leads (path = Online Store)
  * Store customer login -> CRM "App customers"
  * Admin ka ek hi login: CRM aur Store Admin dono me same
  * Dealer/Influencer ke link (?ref=...) se aaya order/enquiry unke naam se dikhta hai

BACKUP
