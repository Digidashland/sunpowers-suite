GUIDE 2 — DNS RECORDS (domain provider ko ye dein)
==================================================
Domain: sunpowers.in      Sab hosting: Vercel      Email (OTP): Resend

A) WEBSITE + APPS (Vercel)
   Type    Name (Host)   Value                    Kiske liye
   ------  ------------  -----------------------  ---------------------------
   A       @             76.76.21.21              sunpowers.in  (Website)
   CNAME   www           cname.vercel-dns.com     www.sunpowers.in (Website)
   CNAME   store         cname.vercel-dns.com     Online Store (Main App)
   CNAME   admin         cname.vercel-dns.com     Store Admin Panel
   CNAME   crm           cname.vercel-dns.com     CRM

   ⚠ Pehle har Vercel project me Settings → Domains me domain jodein:
       Website project → sunpowers.in  aur  www.sunpowers.in
       Main App project → store.sunpowers.in
       Admin project → admin.sunpowers.in
       CRM project → crm.sunpowers.in
     Vercel jo value dikhaye (kabhi "xxxx.vercel-dns-017.com" jaisi nayi value) — WAHI dein.
     Upar wali table aam value hai; Vercel ki screen ko sahi maanein.
   ⚠ Agar "@" ya "www" par pehle se MilesWeb ka A/CNAME record hai to use HATA dein.
     MX (email) wale purane records mat chhedein.

B) RESEND (OTP email ke liye)
   Resend → Domains → sunpowers.in → jo records dikhte hain, WAHI copy karein
   (har account ki value alag hoti hai). Naye Resend me aam taur par ye 3 aate hain:

   Type    Name (Host)          Value (Resend se poora copy)
   ------  -------------------  ----------------------------------------
   TXT     resend._domainkey    p=MIGfMA0GCSqGSIb3DQEB....  (lambi DKIM key)
   CNAME   rsend                rsend-ap....                 (SPF / sending)
   CNAME   send                 send.for....                 (SPF / sending)
   TXT     _dmarc  (optional)   v=DMARC1; p=none;

   (Purane Resend account me "send" par MX + TXT aate the — jo screen par dikhe wahi daalein.)
   ⚠ Name me sirf "send" / "rsend" / "resend._domainkey" likhein — ".sunpowers.in" provider khud jodta hai.
   ⚠ Value ke aage domain jud jaye (….sunpowers.in) to value ke aakhir me point (.) lagayein.
   ⚠ "send" ya "rsend" naam ka koi purana record ho to pehle hatayein (CNAME ke saath doosra record nahi chalta).
   ⚠ Cloudflare ho to CNAME par "DNS only" (grey cloud).
   ⚠ "Enable Receiving" OFF hi rehne dein.

C) CHECK
   • 10 minute – 24 ghante me chalu hota hai
   • Vercel → Domains me sab "Valid Configuration" (hara) dikhe
   • Resend → Domains me "Verified" dikhe
   • Phir CRM → Settings → Login & Email OTP → "Test email bhejein"

Subdomain list (yaad rakhne ke liye)
   www.sunpowers.in   → Website
   store.sunpowers.in  → Online Store / Main App (customer login bhi yahin)
   admin.sunpowers.in → Store Admin Panel
   crm.sunpowers.in   → CRM (team, dealer, influencer)
   send.sunpowers.in  → sirf email ke liye (koi website nahi)
