GUIDE 1 — SUPABASE + RESEND (aap khud karenge, ~15 minute)
==========================================================
Project: https://fotmykjrqrgjnzqbdsea.supabase.co

STEP 1 — pg_net chalu karein (email bhejne ke liye zaroori)
  supabase.com → apna project → Database → Extensions
  → search "pg_net" → switch ON (schema: extensions) → Enable

STEP 2 — Database RUN karein
  SQL Editor -> New query
  Naya khali project:  MASTER-FRESH.sql poori copy -> paste -> RUN
     (badi file na chale to SQL-PARTS/ ke F01..F06 phir U01..U10 order se — SQL-KAISE-CHALAYEIN.txt)
  Neeche "Sunpowers CRM setup complete" aana chahiye. Dobara chalane se data nahi mitta.
  (Purana project jahan pehle se chal raha hai: MASTER-UPDATE.sql — 0-LIVE-UPDATE-PEHLE-YAHI-PADHEIN.txt dekhein.)

STEP 3 — Resend key Vault me rakhein (sabse surakshit)
  Resend.com → API Keys → "Create API Key" (Sending access) → copy (re_... se shuru)
  (Purani key jo chat me di thi use "Revoke" kar dein.)
  SQL Editor → New query → ye likhein (apni key daal kar) → RUN:

      select vault.create_secret('re_APNI_NAYI_KEY', 'resend_api_key');

  Key badalni ho baad me:
      select vault.update_secret(id, 're_NAYI_KEY') from vault.secrets where name = 'resend_api_key';

  (Doosra tareeka: CRM me login ke baad Settings → "Login & Email OTP" → key paste → PIN → Save.
   Vault wali key ko pehle mana jata hai.)

STEP 4 — Resend me domain verify (bina iske email sirf aapke Resend account wale
         email par hi jayega)
  Resend → Domains → Add Domain → sunpowers.in → jo records dikhenge wo GUIDE-2-DNS.txt
  ke hisab se domain provider ko dein → "Verified" aane tak ruken.
  Tab tak jaldi test karna ho: CRM Settings → Login & Email OTP → "From" me likhein
      Sunpowers <onboarding@resend.dev>
  (Ye sirf us email par bhejta hai jisse Resend account bana hai — isliye Resend account
   helpsunpowers@gmail.com se hi banayein.) Verify ke baad wapas likhein:
      Sunpowers <no-reply@sunpowers.in>

STEP 5 — Pehla Admin login (CRM: crm.sunpowers.in)
  1. "Mobile / Email / Username" me likhein: admin → "Aage badhein" → helpsunpowers@gmail.com par 6 ank ka code
  2. Code daalein → apna 6 ank ka PIN banayein → 2 security sawal + jawab
  3. Settings → "Login & Email OTP" → "Test email bhejein" → status "delivered" aaye to sab sahi
  Email na aaye to: wahi page "Aakhri 20 email" me laal note padhein
     • "key nahi" → Step 3     • "pg_net band" → Step 1     • domain error → Step 4
  Emergency: OTP ki jagah "Master password" (purana Store Admin password) + PIN
