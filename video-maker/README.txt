VIDEO MAKER (text -> video) — website ke 20 explainer video yahin se bante hain
1) videos.js me text badlein (Hinglish). Har video ke scene: title / points / flow / steps / stat.
2) Computer par Node + Playwright + ffmpeg chahiye:  npm i playwright   (ffmpeg installed ho)
3) Chalayein:  node gen.js ongrid subsidy     (ya sabhi key)   -> out/<key>.mp4 + out/<key>.jpg
4) Naye mp4 + jpg ko website/assets/video/ me rakh dein, phir deploy.
Note: gen.js ke andar path (/home/claude/vidgen) apne folder ke hisaab se badal lein.
